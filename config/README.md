# Config 目錄

> **Linus 哲學：好的預設值勝過一千個選項**

## 檔案說明

| 檔案 | 用途 | 你需要它嗎？ |
|------|------|-------------|
| `minimal.yaml` | Layer 0 極簡模式 | ❌ 不需要 |
| `standard.yaml` | Layer 1 智慧路由（預設） | ❌ 不需要 |
| `enterprise.yaml` | Layer 2 企業功能 | ❌ 絕對不需要 |

## 如何配置？

**答案：不要配置。**

預設值已經是最佳值。如果你覺得需要修改配置，那是設計的問題，不是配置的問題。

## 真的需要改？

```bash
# 唯一需要的配置
export OPENAI_API_KEY="sk-..."

# 其他都是浪費時間
```

## 為什麼這些檔案還在？

向後相容。Linus 說過："Never break userspace"。

但你不應該用它們。
